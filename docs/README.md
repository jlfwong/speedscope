# Showcase Content

This directory contains the source content for the public showcase site in `site/`.

## Main sections

- `overview/`: repo map and start-here material
- `cloud-agents/`: the orchestration story
- `architecture/`: old vs new system explanations
- `demo/`: side-by-side validation flow
- `benchmarks/`: committed metrics and benchmark narrative
- `data/`: checked-in benchmark and fixture data consumed by the site

Run the site locally with:

```bash
npm run showcase:dev
```
