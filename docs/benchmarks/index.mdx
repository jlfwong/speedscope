# Benchmarks

The benchmark story in this repo is intentionally conservative. The evidence is strongest on the sampled Speedscope JSON path, because that is the path that has actually been ported into Rust/WASM so far.

## How to reproduce the synthetic runs

<CommandBlock
  title="Medium synthetic sampled run"
  command="npm run experiment:benchmark-rust-sampled -- --samples=250000 --runs=5"
/>

<CommandBlock
  title="Larger sampled run"
  command="npm run experiment:benchmark-rust-sampled -- --samples=500000 --runs=3 --skip-parity=1"
/>
