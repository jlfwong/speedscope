# Benchmarks

The benchmark story in this repo is strongest on the sampled Speedscope JSON path, because that is the path that has actually been ported into Rust/WASM so far. After changing the JS/WASM boundary to use typed-array tables instead of millions of JS node objects, the large synthetic sampled cases now show the Rust path winning on both wall-clock time and memory.

## How to reproduce the synthetic runs

<CommandBlock
  title="Medium synthetic sampled run"
  command="npm run experiment:benchmark-rust-sampled -- --samples=250000 --runs=5"
/>

<CommandBlock
  title="Larger sampled run"
  command="npm run experiment:benchmark-rust-sampled -- --samples=500000 --runs=3 --skip-parity=1"
/>

<CommandBlock
  title="112 MB head-to-head sampled run"
  command="npm run experiment:benchmark-rust-sampled -- --samples=1000000 --runs=1 --skip-parity=1"
/>

<CommandBlock
  title="Generate the 112 MB uploadable demo file"
  command="npm run experiment:benchmark-rust-sampled -- --samples=1000000 --runs=1 --skip-parity=1 --write-file=demo/fixtures/generated/synthetic-sampled-1m.speedscope.json"
/>
