# Start Here

This repository is a showcase-first fork of Speedscope. It preserves the original application while documenting a real migration of the hottest sampled-profile import path to Rust/WASM with Cursor cloud agents coordinating the work.

![Speedscope UI](https://user-images.githubusercontent.com/150329/40900669-86eced80-6781-11e8-92c1-dc667b651e72.gif)

<Callout title="What you should notice first" tone="success">
The point of this repo is not "we rewrote everything." The point is that we kept the original Speedscope UI and much of the original codebase intact, inserted a measured Rust seam where it mattered, and used a cloud-agent control plane to make the migration tractable.
</Callout>
